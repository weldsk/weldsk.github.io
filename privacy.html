プライバシーポリシー

claude-mcp は、所有者が自分の Google アカウントのデータを読むためだけに使う個人用ツールです。

  • 読み取るデータ: Gmail のメールと Google カレンダーの予定(読み取り専用の権限のみ)。
  • 使い道: 所有者本人への要約と報告だけに使います。
  • 保存: 認証情報は所有者の PC にだけ保存し、外部のサーバーには置きません。
  • 第三者への提供: 行いません。販売や広告には使いません。
  • 取り消し: Google アカウントの「サードパーティ製のアプリとサービス」からいつでもアクセスを取り消せます。

Privacy Policy

claude-mcp is a personal tool used only by its owner to read their own Google account data.

  • Data accessed: Gmail messages and Google Calendar events, with read-only scopes.
  • Use: Only to produce summaries for the owner.
  • Storage: Credentials are stored only on the owner's computer, not on any external server.
  • Sharing: No data is shared with, sold to, or used for advertising by any third party.
  • Revocation: Access can be revoked at any time from the Google Account "Third-party apps & services" page.

Google API の利用は Google API Services User Data Policy(Limited Use を含む)に従います。 / Use of Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
