# weldsk.github.io

Google Cloud の OAuth アプリ `claude-mcp`(プロジェクト `claude-mcp-514005`)を「本番」に公開するために置いたホームページとプライバシーポリシー。

## 目的
- OAuth アプリが「テスト中」だとリフレッシュトークンが 7 日で切れる。公開するにはブランディング画面にホームページ・プライバシーポリシーと承認済みドメインが要るため、そのページをここに置いた。
- 本番に公開しても未確認アプリのまま(個人用、ユーザー 100 人まで)で使う。

## 中身
- `index.html`: ホームページ(https://weldsk.github.io/)
- `privacy.html`: プライバシーポリシー(https://weldsk.github.io/privacy.html)
- 個人情報(メールアドレスなど)は書かない。

## ブランディング画面に入れる値
- ホームページ: https://weldsk.github.io/
- プライバシーポリシー: https://weldsk.github.io/privacy.html
- 承認済みドメイン: weldsk.github.io
